# Report 07 - Resultados da Pesquisa

- Título: `Resultados da Pesquisa`
- Objetivo de negócio: entregar ao cliente o resultado de uma pesquisa específica.
- Público: externo.
- Cards/KPIs:
  - empresas participantes
  - percentual do mercado coberto
  - perguntas
  - tempo médio
- Visuais:
  - distribuição das respostas
  - pergunta-chave
  - tabela de destaques por questão
- Dados necessários:
  - `respostas`
  - `questoes`
  - `respondentes`
  - `empresas.% de mercado`
  - `pesquisas.tempo_preenchimento`
- Status de viabilidade com a base atual: `Parcial`
- Principais lacunas/riscos:
  - funciona bem para perguntas fechadas; respostas abertas exigem tratamento adicional.
  - a narrativa de “pergunta-chave” e “destaques” depende de curadoria analítica por pesquisa.
  - pesquisas com pouca documentação contextual podem gerar leitura pobre mesmo com dados válidos.
