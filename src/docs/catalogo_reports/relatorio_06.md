# Report 06 - Engajamento & Adesão

- Título: `Engajamento & Adesão`
- Objetivo de negócio: mostrar quais empresas participam, quais somem e onde agir para reengajar.
- Público: interno.
- Cards/KPIs:
  - adesão média
  - empresas ativas
  - empresas que nunca participaram
  - total de respondentes
- Visuais:
  - barras de adesão por pesquisa
  - mapa/região de empresas
  - tabela de empresas a reengajar
- Dados necessários:
  - `respondentes.id_empresa`
  - `empresas.ID`
  - `empresas.Estado` ou `empresas.País`
  - `pesquisas.id`
- Status de viabilidade com a base atual: `100% possível`
- Principais lacunas/riscos:
  - o conceito de “empresa a reengajar” precisa de régua de negócio definida pelo grupo.
  - o mapa pode exigir normalização geográfica simples a partir de `Estado`/`País`.
