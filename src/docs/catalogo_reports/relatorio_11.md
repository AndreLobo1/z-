# Report 11 - Comparativo Anual & Tendências

- Título: `Comparativo Anual & Tendências`
- Objetivo de negócio: mostrar o que muda de uma onda ou ano para outro.
- Público: externo.
- Cards/KPIs:
  - número de ondas
  - período
  - variação de adesão
  - tendência-chave
- Visuais:
  - linha de evolução do indicador
  - composição por ano
  - tabela do que mais mudou
- Dados necessários:
  - `pesquisas.data_solicitacao`
  - `pesquisas.tipo`
  - `pesquisas.status`
  - indicadores apurados por ano/onda
- Status de viabilidade com a base atual: `100% possível`
- Principais lacunas/riscos:
  - “onda” precisa ser definida de forma consistente pelo grupo para não misturar pesquisas incomparáveis.
  - a leitura causal do que mudou depende de contextualização analítica adicional.
