# Legado Streamlit

Esta pasta preserva a antiga visualização baseada em Streamlit e geradores HTML auxiliares.

## Status

Legado. Não é mais a interface principal de documentação do projeto.

## Conteúdo

- `streamlit_dashboard.py`: app original do relatório
- `gerar_dashboard_html_completo.py`: gerador de dashboard HTML completo
- `gerar_html_offline.py`: gerador de HTML offline do relatório
- `sidusfarma_analytics_complete.html`: saída HTML antiga
- `relatorio_offline.html`: saída HTML offline antiga

## Diretriz atual

O fluxo principal de documentação passa a ser `MkDocs` sobre a pasta `docs/`.
